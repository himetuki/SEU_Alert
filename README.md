# QQ消息集散（qq-relay）

> 版本 v0.4 · 2026-10-25 · P0+P1 代码落地（58 项测试全绿），等 NapCat 下载完成后解压、你扫码登录

校内个性化信息推送：把分散在**学习通、雨课堂、QQ、微信和学校各类网站**上的课程作业、考试时间、DDL、科研竞赛、国际交流、讲座活动等信息，聚合成每个学生**按需订阅**的推送。

## 痛点

大学里很多重要信息分散在上述平台。课程作业、考试时间、DDL、科研竞赛、国际交流、讲座活动等，同学需要自己在不同平台反复查找，经常遗漏重要通知。

## 方案概要

个人 QQ 小号接入 bot 框架（NapCat / OneBot 11）常驻各类 QQ 群 → 实时捕获群消息 → **渠道画像 + 预筛 + JEV 分类树** → 按需信息提取（DDL 等）→ 按「群 × 类别」订阅匹配 → QQ 私聊即时推送 / 定时 Digest。

- 采集层后续可扩展：学校网站爬虫、用户转发上报（学习通/雨课堂消息转发给 bot）
- 分发主通道 QQ 私聊；微信侧用 WxPusher 类推送服务降级实现
- 低置信分类进入人工复核队列（"人类完成分发"的固化形态）

## 范围

| | 内容 |

## 参与修改的约定

1. **先改文档再改代码**：任何设计变更先更新 docs/，保持文档是唯一权威
2. **决策必须留痕**：每个设计决策在 decisions.md 追加一条 ADR（背景/决定/理由/被否方案/后果），改决策时新增 ADR 而非静默修改旧条目
3. **配置 schema 唯一权威在 config.md**：代码实现以它为准
