# 验收标准（流程1 功能验收）

> 版本 v0.2 · 2026-10-25 · "工作流打通"的可检验定义。全绿再谈后续流程（爬虫/上报/微信）。**测试期验收全部基于文件分发（outbox/<用户QQ>/*.txt，ADR-021）；真实 QQ 推送口径在试点审批后另立。**

## A · 管道

| # | 标准 | 度量 |
|---|---|---|
| A1 | 小号在 ≥3 个群在线，群消息到达业务进程 | 延迟 ≤5s 且可观测（不能只看"收到了"） |
| A2 | 预筛真实跑 24h | 命中率落在 10–20%；抽 20 条被漏通知人工看误杀率 |
| A3 | 端到端分发 | 往测试群贴一条合成"作业通知"，30s 内 `data/outbox/<主号QQ>/` 下出现对应 txt |
| A4 | Digest | 定时摘要任务产出 `digest-<date>.txt` 到对应用户目录 |
| A5 | **负类静默（生死线）** | 灌水群 24h outbox 零新增文件。宁漏勿误 |
| A6 | 掉线看门狗 | kill 掉 NapCat，管理员收到告警 |
| A7 | 迁移彩排 | 全栈在香橙派上跑通 24h（含扫码登录、掉线重连）——**迁移动作本身**也是验收项 |

## B · 分类器

| # | 标准 | 度量 |
|---|---|---|
| B1 | 根调用 cat 准确率 | 金标准集上 ≥80%；跨界样本（讲座+竞赛）能标出 cat2 |
| B2 | 分支只在正类触发 | JEV 调用计数：branch 调用数 ≈ 正类消息数 |
| B3 | L4 触发率 | < 正类的 10% |
| B4 | L4 deadline 正确率 | 与人工标注一致 ≥80%；解析失败 100% 有回落，不允许静默丢失 |
| B5 | research stage 识别 | SRTP 样本 ≥15 条；试点群没有则从复制通知补、标注"样本外" |
| B6 | competition 双 deadline 配对 | 报名 vs 作品不混为一个日期 |
| B7 | 成本可见 | JEV 调用数、小模型调用数、token 用量全部落库，超预算报警 |
| B8 | choice 低置信路由 | 前两名概率接近的样本进人工复核队列，队列非空且被处理 |

## C · 画像与过滤

| # | 标准 | 度量 |
|---|---|---|
| C1 | 画像覆盖 | bot 所有在群 100% 有画像；绑定课程抽检 10 群人工核对 |
| C2 | 按群分组统计 | 根调用准确率按群分别统计；"画像先验与内容判断不一致"样本单独列出（画像设计风向标） |
| C3 | 预筛漏检按群统计 | 验证通用词 ∪ 画像词的并集兜住了画像词收窄带来的盲区 |
| C4 | dry-run 验证 | 开启任一群发送者过滤前，24h dry-run 报告的 M 值（被滤且关键词命中）人工核对并接受为已知漏报基线 |
| C5 | 订阅命中矩阵 | 抽 20 组"群 × 类别"组合逐一验证命中/不命中；cat2 的 OR 语义是重点 case |
| C6 | 画像审计 | 画像每次变更（谁/何时/改什么）有日志；/filter audit 能产出被滤关键词命中清单 |

## 金标准集要求

- 40–50 条**真实**通知（从任何渠道复制的真通知均可），覆盖 9 类；SRTP/research 类 ≥15 条、chat 类 8–10 条
- 每条带人工标注：cat（+cat2）、urg、has_ddl 及 deadline 标准值（拿不准填 null）
- **模板**：`data/goldset.template.jsonl`（每类一条示例）；**采集指南**：`data/goldset.README.md`（含各类配额与"棘手样本"清单）
- 成品放 `data/goldset.jsonl`（gitignore，只留本机）；跑 `.venv\Scripts\python scripts\run_goldset.py` 出 `data/goldset-report.md`
- 同时用作：验收基准、题干校准依据、回归测试集（改题干/关键词/阈值后必须重跑对比，不允许悄悄变差）
