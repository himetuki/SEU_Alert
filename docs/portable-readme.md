# QQ消息集散 · 便携版使用说明（使用者版）

> 版本 v0.1 · 2026-10-26 · 本版本为**基础版**：先跑通"监控 → 分类 → PushPlus 推送"主链路，
> 配置项后续版本逐步开放。使用中遇到任何问题，请把 `logs/` 目录和后台截图反馈给维护者。

## 一、这是什么

一个在后台自动监控校园信息的软件，当前重点监控两个源：

- **人文讲座**（东南大学讲座预约系统）：自动列出可预约讲座、开放时间、余量
- **劳动教育**（劳动教育课程平台）：有新课程自动提醒

监控到的信息会按订阅规则，通过 **PushPlus（微信推送）** 发给订阅者。

## 二、怎么启动

1. 把整个 `qq-relay-portable` 文件夹拷贝到电脑上（放哪都行，建议放非系统盘）
2. 双击 **`qq-relay.exe`**
3. 等几秒，浏览器会自动打开后台管理页面（地址是 `http://127.0.0.1:8000`；
   没自动开就手动在浏览器输入这个地址）
4. 看到"监控源"表格就说明启动成功了。**关闭黑色命令行窗口 = 停止软件**

## 三、第一次使用要配三样（都在后台页面操作）

### 1. PushPlus token（必须，否则推送只落在本地文件夹）

- 微信扫码关注"PushPlus"公众号 → 左下角"账号"→ 复制你的 token（一长串字符）
- 用记事本打开软件目录下的 **`.env`** 文件（如果没有这个文件，先把 `.env.example`
  复制一份、改名为 `.env`），找到 `PUSHPLUS_TOKEN=`，把 token 填到等号后面，保存
- 多个使用者可以填**同一个** token（大家收到同样的推送）；想分别推送再每人一个
- 改完**重启软件**，在后台页面点"发送测试"，微信收到即成功

### 2. 讲座/劳动教育登录账号（必须，否则这两个源扫不到东西）

- 同样是 `.env` 文件，填：
  - `SEU_LECTURE_USERNAME=` 一卡通号
  - `SEU_LECTURE_PASSWORD=` 统一身份认证密码
  - `LABOR_USERNAME=` 一卡通号（一般同一个）
  - `LABOR_PASSWORD=` 同上
- 保存后重启软件。**需要在校园网环境（或连上学校 VPN）才能登录成功**
- 如果学校要求短信验证码，软件会跳过这一轮并在页面上显示错误，下次自动重试；
  遇到验证码卡住，把日志反馈给维护者

### 3. 订阅规则（谁收什么）

在后台"订阅管理"区添加：

| 字段 | 填什么 |
|---|---|
| 用户QQ | 接收人备注（测试期随便填，如 tester1） |
| 群 | 群名，要和"配置概览"里显示的一致，如 `人文讲座（预约系统监控）`、`劳动教育课程平台` |
| 类别 | 用中文：讲座、任务、通知（多个用逗号隔开） |

**保存后要重启软件才生效**（基础版的已知限制，下个版本优化）。

## 四、日常看什么

- **监控源表格**：每个源的"上次扫描"时间应该在持续走动；"错误"列出现红色说明该源失败
  （校园网断了、登录过期都会这样），点"立即扫描"可以手动重试
- **最近信息流**：扫到的讲座/课程会列在这里，能看到题目、来源、截止时间
- **想立刻看推送效果**：在"PushPlus 测试推送"区点"发送测试"

## 五、文件都放在哪

```
qq-relay-portable/
├── qq-relay.exe        ← 双击启动
├── .env                ← 密码/token 填这里（改完重启）
├── config/             ← 监控配置（一般不用动）
├── data/               ← 数据库和 outbox（没配 token 时推送落这里）
└── logs/               ← 运行日志（出问题把这个发给维护者）
```

## 六、常见问题

| 现象 | 怎么办 |
|---|---|
| 浏览器没自动打开 | 手动访问 http://127.0.0.1:8000 |
| 页面打不开 | 看黑色窗口是否报错；多半是端口被占，关掉别的程序再试 |
| 讲座/劳动教育一直错误 | 确认在校园网内；确认 .env 账号密码没错；要短信验证就等下一轮或反馈日志 |
| 微信收不到推送 | 确认 .env 里 PUSHPLUS_TOKEN 填了并重启过；用"发送测试"验证 |
| 想换推送对象 | 改 .env 的 PUSHPLUS_TOKEN，或在订阅管理里改用户 |
